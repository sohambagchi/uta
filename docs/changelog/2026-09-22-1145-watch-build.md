# 2.0.0: watch build

Marks convergence of the analytics dashboard (1.0.0), station search (1.0.1) and the mobile pass (1.0.2–1.0.8).

- `npm --prefix web run watch`: `vite build --watch` into `src/uta/static/`; a dev-shell `python -m uta serve` serves each rebuild on reload.
- `serve` mounts `/assets` even when it doesn't exist yet at startup, so serve and watch can start in either order.
