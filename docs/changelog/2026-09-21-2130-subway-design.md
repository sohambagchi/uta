# Subway-map UI overhaul

- NYC-subway palette and signage: black header band, A–D shown as colored line bullets across cards, legend, tables, tooltips and chart end labels.
- Friendlier layout: Inter font, larger type, rounded cards with soft shadows, pill controls, plain-language labels, a three-step welcome panel.
- Stop list is a strip map with "Get on" / "Get off" tags and a prompt for the next step.
- Map: rail lines in UTA colors, restyled legend/controls, friendlier vehicle popup.
- Light mode by default, with a header toggle for dark mode (remembered per browser); the basemap follows it.
- Rationale: ADR [2026-09-21-2130-subway-design](../adr/2026-09-21-2130-subway-design.md)
