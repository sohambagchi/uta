# Visual design: NYC-subway signage, light by default

**Status:** accepted (supersedes the theme part of [2026-09-21-2038-maplibre](2026-09-21-2038-maplibre.md))

**Context:** The first dashboard used a neutral palette and followed the OS color scheme. It read like an analyst's tool; the goal is something friendlier that a rider can pick up.
**Decision:** Borrow NYC subway signage. There is a black sign band header with a white pinstripe. Comparison slots A–D use trunk-line colors (A/C/E blue `#0039a6`, B/D/F/M orange `#ff6319`, 4/5/6 green `#00933c`, 7 purple `#b933ad`) and appear as round "bullets" wherever a slot is named, including as direct labels on charts. The stop list is drawn as a strip map. Rail lines on the map use UTA's own route colors. Vehicle delay keeps its own labelled status colors (MTA yellow / lime / orange / red). The font is Inter (bundled via `@fontsource-variable/inter`, so it looks the same on every OS). Copy is in plain language ("Typical", "Is it keeping to the timetable?"), and the exact statistics are kept in tooltips.
**Theme:** Light is the default. A header toggle switches to dark; the choice is stored in `localStorage` (`uta-theme`) and stamped on `<html data-theme>` before first paint. The OS preference is no longer consulted. The basemap follows the toggle.
**Consequences:** Adding the font package changed `npmDepsHash`. A dark palette is defined only under `[data-theme="dark"]`. Plot marks that need a fixed fill (white bullet letters) set `ariaLabel: "bullet"` so the global `.plot-figure text` rule doesn't recolor them.
