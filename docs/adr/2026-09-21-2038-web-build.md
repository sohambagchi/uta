# Dashboard: Svelte 5 + TypeScript + Vite, built by Nix

**Status:** accepted

**Context:** The old dashboard was a 640-line vanilla-JS IIFE with hand-drawn SVG charts and no shared state. The overhaul adds a route-segment comparison UI with a live map, which needs components, reactive state, and real chart and map libraries.
**Decision:** `web/` holds a Svelte 5 + TypeScript app built with Vite. Charts use Observable Plot, the map uses MapLibre GL. `npm run build` writes into `src/uta/static/` (gitignored). The flake builds it with `buildNpmPackage` (`packages.web`) and copies it into the Python package before building.
**Alternatives:** React (more boilerplate for the same result); keep vanilla JS with no build step (doesn't scale to the new UI); ECharts (heavier, and harder to match the dataviz mark specs).
**Consequences:** Node is part of the dev shell. `npmDepsHash` must be updated whenever the lockfile changes. A plain `pip install` without a web build serves a "not built" page.
