# Map: MapLibre GL with OpenFreeMap vector tiles

**Status:** accepted

**Context:** The Leaflet map redrew every marker every 30 s (popups closed, no motion), showed one route shape at a time, and used raster OSM tiles, whose usage policy doesn't suit heavy use.
**Decision:** MapLibre GL 6. GeoJSON sources are updated in place, and vehicles are interpolated between polls. The basemap is OpenFreeMap positron/dark, which needs no API key, and follows `prefers-color-scheme`. MapLibre's tile worker is bundled via Vite (`?worker&url` + `setWorkerUrl`); without it no tiles render.
**Consequences:** Basemap tiles are the only third-party network dependency. Map colors are read from CSS tokens at style load, so a theme switch reloads the style.
